# Manafold branding

This directory contains the first Manafold company-logo lockups for public
documentation and Discord.

## Concept

The mark is an abstract folded `M` made from two interlocking planes. The
wordmark is always included. The design uses a technical, restrained palette:

- Graphite: `#111827`
- Electric teal: `#19D3C5`
- Off-white: `#F4F7F8`

## Files

- `manafold-logo-horizontal.svg` — primary light-background lockup.
- `manafold-logo-horizontal-dark.svg` — primary dark-background lockup.
- `manafold-logo-compact.svg` — square light-background lockup for Discord.
- `manafold-logo-compact-dark.svg` — square dark-background lockup for Discord.
- `manafold-logo-horizontal-mono.svg` — graphite monochrome lockup.
- `manafold-logo-horizontal-mono-dark.svg` — off-white monochrome lockup.
- `manafold-logo-compact-mono.svg` — graphite compact monochrome lockup.
- `manafold-logo-compact-mono-dark.svg` — off-white compact monochrome lockup.

All files have transparent backgrounds and contain no remote asset references.
Use the horizontal lockup in document headers and the compact lockup in square
profile placements. Do not crop the wordmark out of the approved lockups.
