# Glossary

**Status:** accepted informative vocabulary  
**Stability:** informative


- **authoritative replay:** exact semantic episode evidence, not an ML trajectory.
- **capability:** versioned executable semantic unit.
- **capability bundle:** closed format/card/mechanic/schema/evidence set.
- **candidate:** one request-local legal choice atom.
- **continuation:** serializable suspended semantic computation awaiting choice.
- **full state:** privileged actual game state.
- **information state:** perspective-safe current observation plus relevant history.
- **observation:** what a player perceives now.
- **opaque ID:** perspective-safe identity with controlled lifetime.
- **semantic key:** versioned dataset-oriented action meaning, not legality source.
- **soundness:** every offered choice is legal.
- **completeness:** every legal choice is representable.
- **terminal:** game ended by rules/concession.
- **truncation:** environment stopped for technical policy/resource reason.
