# External Source Registry

Store only provenance manifests, hashes, retrieval instructions, licenses, and
normalization reports here unless redistribution rights are confirmed. Do not
commit card images or unreviewed bulk card data.

Every source entry should record:

- immutable source identifier and retrieval date;
- upstream URL or publication identity;
- cryptographic digest of the exact artifact;
- usage and redistribution basis;
- normalization tool version and output digest;
- supersession history;
- whether the artifact is required to reproduce a certified replay.

Rules, Commander policy, banlist, Oracle data, and official rulings are separate
snapshot identities even when retrieved on the same date.
