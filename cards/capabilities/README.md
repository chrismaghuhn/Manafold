# Capability Registry

`registry.json` is the project registry. The M3 Pre-T0 hardening candidate
registers the eleven reviewed Initial Foundation identities at lifecycle
`specified`; this is not an implementation, coverage, certification, card, or
deck support claim. `registry.example.json` demonstrates the schema without
claiming support.

Use `python scripts/scaffold_capability.py <key> <title>` to add a proposal. Lifecycle and certification rules are defined in `docs/cards/CAPABILITY_MODEL.md`.
