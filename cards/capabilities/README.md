# Capability Registry

`registry.json` is the project registry. Ten Initial Foundation capabilities
remain specified-only. `rules/turn-structure@0.1.0` is implemented for the
bounded M3.S1 scope; coverage and certification are not claimed, and this does
not claim card, deck, format, Commander, broad Magic, or playability support.
`registry.example.json` demonstrates the schema without claiming support.

Use `python scripts/scaffold_capability.py <key> <title>` to add a proposal. Lifecycle and certification rules are defined in `docs/cards/CAPABILITY_MODEL.md`.
