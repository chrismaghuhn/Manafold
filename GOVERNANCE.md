# Governance

**Status:** accepted governance baseline  
**Stability:** normative


Until a broader maintainer group exists, the project owner is final decision
maker and must appoint named stewards for rules semantics, information safety,
release engineering, and ML contracts before V1 certification.

Accepted ADRs are immutable history. A new ADR supersedes an old one. Rules
changes require pinned authority and executable conformance evidence. Security
or hidden-information concerns may block a release independently of feature
status. No maintainer may unilaterally waive an acceptance gate without a public
ADR naming the risk and scope.
